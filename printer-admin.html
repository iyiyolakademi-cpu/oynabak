Windows Hızlı Yazıcı Kurulumu

İşletmenin Windows bilgisayarına Node.js kurmadan tek programla yazıcı bağlayın. Yazıcı Ethernet kablosuyla aynı ağa bağlı olmalı.

Windows Kurulum Dosyasını Görüntüle

GitHub sürümlerindeki OynaBak-Yazici.exe dosyasını kullanın. Derleme henüz yayımlanmadıysa GitHub sürümlerinde görünmez. Programı açın → Cihaz Eşleştir anahtarını yapıştırın → Yazıcıları Bul → Test Fişi → Kaydet.

Yazıcı ayarları

Gerçek yazıcı testi tamamlanmadan otomatik yazdırmayı etkinleştirmeyin. Cihaz eşleştirme ve test sonrası yalnızca İyi Yol Akademi yöneticisi etkinleştirebilir.
Gerçek yazıcıdan deneme fişi çıkmadan otomatik yazdırmayı açmayın. İşletme bilgisayarında KURULUM-BASLAT.cmd çalıştırıp kâğıt ve Türkçe karakterleri doğrulayın.

Eşleştirilmiş Yazıcı Cihazları

Her bilgisayara yalnızca seçili işletmenin sipariş kuyruğunu açan özel cihaz anahtarı verilir. Anahtar yalnızca oluşturulurken görüntülenir.
